# RUSH KITCHEN — Starline Diner

A fast burger-joint arcade game for the make.fun best cooking game bounty.

**Play:** open `game/index.html` in a desktop browser — no server, no network needed.

**How it plays:** tickets come in on the order rail with a patience timer. Grill the patty (lift it in the PERFECT zone), stack the burger in recipe order on the build plate (keys 1–6 or click the ingredient rail), then ring the bell (Space) to serve. Perfect sears and fast serves earn tips; wrong orders and burnt patties cost you. One shift lasts 90 seconds — serve as many burgers as you can.

**Controls:** mouse click everywhere · `1–6` ingredients · `G` grill / lift · `Space` serve · `X` trash · `M` mute · `Enter` start.
